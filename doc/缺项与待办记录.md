> 记录当前尚未实现 / 以降级方式实现的功能点，供后续迭代与后端联调对照。

## 二、降级 / 技术债项

| 项目 | 现状 | 理想方案 |
|------|------|----------|
| 用户体系 | preferences 本地存储，密码明文（演示约定） | 后端真实注册/登录 + Token 鉴权 + 密码加密 |
| 订单/桩状态一致性 | 订单持久化，但桩 `CHARGING` 翻转仅内存生效（重启复位）；进行中的充电会话 `currentOrder` 不持久化 | 后端会话模型；前端重启后按 CHARGING 订单恢复会话 |
| 充电数据 | `ChargeSimulator` 本地定时模拟 | 后端实时推送 / WebSocket |
| 扫码 | 模拟识别（随机空闲桩 / 相册选图不解析） | 接入 `@kit.ScanKit` + 相机权限（`module.json5.requestPermissions` 目前为空） |
| 地图 | 自绘 Canvas 示意地图（坐标在 DisplayMeta） | MapKit / 高德 / 天地图（Key 走环境变量，不入仓库） |
| 站点/桩图片 | 渐变色块 + 图标占位 | 后端返回真实图片 URL |
| 定位 | 站点距离为写死常量 | 真实定位（`@kit.Geolocation`，需权限） |
| 超纲功能 | 钱包/充值/发票/爱车/通知/用户详情已撤入口、留代码 | 后端接口就绪后重新挂载导航 |
