## 二、降级 / 技术债项

| 项目 | 现状 | 理想方案 |
|------|------|----------|
| 地图 | **自绘 Canvas 示意地图**（道路/公园/水域 + 站点标记） | 替换为 MapKit / 高德 / 天地图（需申请 Key，配置在环境变量，**不入仓库**） |
| 站点/桩图片 | 渐变色块 + 图标占位 | 后端返回真实图片 URL |
| 充电数据 | 静态模拟（`MockData`） | 后端实时推送 / WebSocket |
| 用户体系 | 无；登录仅前端校验 | 后端真实注册/登录 + Token 鉴权 + 密码加密 |
| 桩状态 | `IDLE/CHARGING/OFFLINE` 仅静态展示 | 对接实时状态 |
| 定位 | 站点距离为写死常量 | 真实定位（`@kit.Geolocation`，需权限） |
| 明文密码 | 代码中出现 `password` 字段（演示用） | 后端鉴权，前端不落明文 |

> ⚠️ 密码等敏感字段仅作前端演示。**严禁**将真实密钥/Token/内网地址写入代码或提交仓库。
